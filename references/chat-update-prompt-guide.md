# 对话更新怎么说（chat-update）

**一句话原则**：像跟助理报进展一样，**一段话说完**就行，不用套模板、不用分条。调用 `laowang-qiuzhi-jindu` 后 Skill 自动解析并更新本地进度 + 飞书表。

## 一段话里尽量带上这些（口语化即可）

不用标签，自然塞进句子里：

- **哪家 + 什么岗**（有业务线就顺带说一句）
- **刚发生了什么**（面完 / 约面 / 做完测评 / 拒信…）
- **阶段说清楚**：做完测评 ≠ 通过测评
- **问了啥、哪题答得虚**（答得虚的会自动进待复盘）
- **你接下来要干嘛**（可选，有的话 Skill 会写进待办）

缺了哪条，Skill 只追问 **1 个**最关键的问题，不会让你填表。

## 推荐示例（一段话）

```text
用 laowang-qiuzhi-jindu：小红书社区增长产品实习今天下午三点左右业务一面刚结束，主要问了兴趣社区战略、发帖量拆解和活跃下降归因，社区用户和亲书作者那套小数指标我讲得有点虚，男性增长对调性的副作用也没展开，这两块记待复盘，简历用的 resume-v3-xhs-community，现在在等二面通知，周五下班前要是还没消息我去官网看一眼。
```

## 其他场景（同样一段话）

**做完测评（别写成已通过）：**

```text
用 laowang-qiuzhi-jindu：美团 AI 产品实习昨晚把北森测评交卷了，还在等结果，别帮我标成通过。
```

**约面试：**

```text
用 laowang-qiuzhi-jindu：字节约了下周一下午三点抖音增长产品业务一面，飞书视频，简历还是 resume-v2-byte。
```

**拒信：**

```text
用 laowang-qiuzhi-jindu：腾讯 IEG 产品策划刚收到邮件拒信了，简历挂，这条可以归档了。
```

**一次说两家：**

```text
用 laowang-qiuzhi-jindu：快手社区产品二面今天下午面完了，指标归因和漏斗拆解答得还行；另外拼多多促销产品实习刚收到笔试通知，周末前要做完，两家都帮我更新一下。
```

## 太简略的反例

```text
❌ 快手二面完了，记一下。
```

Skill 能记，但飞书表里考点、待复盘、下一步会偏空——多补半句「问了啥、哪题虚」就够用。
