# 待复盘队列（review-queue.md）

## 条目格式

```markdown
- [ ] **{公司}-{岗位}** · {日期} · {考点一句话}
  - 来源：{哪轮面试/测评}
  - 状态：未练 / 已写入 mianshi-zhu / 已 mock
  - 备注：…
```

## 去重

同一公司+考点相似 → 合并为一条，note 追加日期，不重复开新条。

## 与 chat-update

用户说「答不好」「卡壳」「记复盘」→ 自动追加；用户只说「面完了」但没提薄弱点 → 不强行加复盘项。

## 闭环

用户后续说「漏斗那题已补进逐字稿」→ 勾选 `[x]`，状态改 `已写入 mianshi-zhu`。
